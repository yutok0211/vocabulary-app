# マップめし（ブラウザ版）

食べログ風の検索UIで、評価軸に **Google マップの評価・口コミ** を使う飲食店検索。
`index.html` 1枚だけで動く（ビルド不要・外部ライブラリなし）。Android 版は `../restaurant-search/`。

## 試し方

`index.html` をブラウザで開くだけ。APIキーが未設定のあいだは **架空店舗のサンプルデータ** で動く。

スマホから使う場合や、キーに HTTP リファラー制限をかける場合は、ローカルサーバーか静的ホスティングで配信する。

```bash
npx serve restaurant-web        # → http://localhost:3000
```

## 実データで検索する

1. [Google Cloud Console](https://console.cloud.google.com/) で課金を有効にし、次の2つを有効化
   - **Maps JavaScript API**
   - **Places API (New)**
2. API キーを作成し、制限をかける
   - アプリケーションの制限：**HTTP リファラー**（例 `http://localhost:3000/*`、公開先の URL）
   - API の制限：上記2つの API のみ
3. 画面右上の「APIキー」からキーを入力（ブラウザの localStorage にだけ保存される）

`file://` で直接開いた場合はリファラーが送られないため、リファラー制限付きのキーは使えない。

## 仕様

- 検索：エリア・駅＋キーワード、または現在地周辺（半径1.5kmを優先）。1回の検索で最大20件
- 並び替え：ランキング（口コミ件数で補正したスコア）／評価が高い順／口コミが多い順／近い順
- 絞り込み：★◯以上、口コミ◯件以上、予算、営業中のみ、予約可のみ（端末側で処理するため API を呼び直さない）
- 詳細：写真、評価、地図・ルート・電話・HP、営業時間、Google の口コミ（最大5件）

補正スコア = (件数 × ★ + 30 × 3.8) / (件数 + 30)。★5.0・口コミ8件のような店が上位を占めないようにしている。

## 注意

- 食べログのデータは使っていない（UI の参考のみ）
- 評価・口コミ・写真には Google の帰属表示と投稿者名が必要（実装済み）
- 料金：★・口コミ件数を取得するため検索は Text Search Enterprise、詳細は口コミを含むため Place Details Enterprise + Atmosphere、写真は1枚ごとに Place Photos が課金される
