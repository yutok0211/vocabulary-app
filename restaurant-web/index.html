    席・設備

    Google マップのデータには禁煙・個室・カウンター席の情報がありません。この3つは「データ」から読み込んだ店舗で使えます。

    Google Maps APIキー

    Google Cloud Console で「Maps JavaScript API」と「Places API (New)」を有効にしたキーを入力してください。キーはこのブラウザにだけ保存されます。

    キーには「HTTPリファラー」の制限をかけ、このページを開くURLだけを許可してください。

    集めたデータを読み込む

    restaurant-scraper の merge で作った restaurants.json を選ぶと、その店舗の中から検索できます。禁煙・個室・カウンター席で絞り込めるのはこのデータです。

    ファイルはこのブラウザの中だけで読み込み、どこにも送信しません。
